## Objective
Create the .vscode/mcp.json template that registers all custom MCP servers plus recommended community servers.

## Acceptance Criteria
- [ ] Template .vscode/mcp.json with mcp-kanban server configuration
- [ ] Template includes mcp-knowledge server configuration
- [ ] Template includes mcp-project server configuration
- [ ] Template includes community Playwright MCP server (if applicable)
- [ ] Template includes community GitHub MCP server (if applicable)
- [ ] Each server entry has correct command, args, and env configuration
- [ ] setup.py generates mcp.json with correct relative paths to owlbear installation
- [ ] All servers start successfully when VS Code opens the project
- [ ] Document how to add project-specific MCP servers

## Context
Depends on M1 (mcp-kanban) as the first server to test with. The mcp.json template is generated by the setup script (F6) but this task defines what goes in it.
