## 3. Analysis

### 3.1 Canonical Config Format

Both S1 and S2 document the same remote server pattern for VS Code `mcp.json`:

```json
"github": {
  "type": "http",
  "url": "https://api.githubcopilot.com/mcp/"
}
```

- **Server name:** `github` (camelCase, matches AC) (S1, S2)
- **Type:** `http` — remote server, no local binary needed (S1, S2)
- **URL:** `https://api.githubcopilot.com/mcp/` (S1 uses trailing slash; S2 omits it)
- **Auth:** OAuth via VS Code + Copilot — zero config needed (S1, S2)
- **Prerequisites:** VS Code 1.101+ (S1)

### 3.2 URL Trailing Slash Discrepancy

| Source | URL used |
|--------|----------|
| GitHub MCP Server README install button (S1) | `https://api.githubcopilot.com/mcp/` |
| VS Code MCP Server Guide example (S2) | `https://api.githubcopilot.com/mcp` |

Both work. The official repo's install link uses the trailing slash. Recommend
matching the official repo: `https://api.githubcopilot.com/mcp/`.

### 3.3 Implementation Scope

| File | Change | Complexity |
|------|--------|------------|
| `scripts/setup.py` | Add `"github"` entry to `config["servers"]` dict (3 lines) | Trivial |
| `tests/test_setup_script.py` | Change server count assertion from 3 to 4 | Trivial |
| `tests/test_setup_script.py` | Add test: github server has `type: http` and correct URL | Small |

### 3.4 Ordering Consideration

The `github` entry should appear **first** in the servers dict — it's the only
server that works out of the box (OAuth, no local deps). The three owlbear stdio
servers depend on local packages that may not yet be implemented. Placing `github`
first makes the config immediately useful.

### 3.5 Risk Assessment

- **No breaking changes** — existing mcp.json files are not modified (idempotent skip)
- **New installs only** — only affects freshly-generated templates
- **Zero external deps** — remote HTTP type requires no local binaries
- **Copilot subscription required** — OAuth via Copilot needs an active subscription (S1)

## 4. Recommendation (.90 confidence)

Add the GitHub MCP server as the first entry in the `create_mcp_config()` servers dict:

```python
"github": {
    "type": "http",
    "url": "https://api.githubcopilot.com/mcp/",
},
```

Update tests:
1. Change `test_mcp_json_has_exactly_three_server_entries` assertion from 3 to 4
2. Add `test_github_server_has_type_http_and_correct_url`
3. Update `test_mcp_server_names_are_camelcase` expected set to include `"github"`

Implementation is straightforward with no design decisions needed.
