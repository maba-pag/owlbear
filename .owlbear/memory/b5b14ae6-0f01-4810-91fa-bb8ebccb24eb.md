In run_in_terminal's persistent zsh session, `path` is a special array tied to PATH. During TASK-001 (delivery-action-readiness), using it as a for-loop variable immediately made both git and uv unavailable and left the terminal's executable search path altered. Use a normal name such as source_file for path iteration; do not reuse path or PATH as temporary variables. This is a shell-environment failure, not missing project dependencies.
