When judging a memory-mcp claim that an identity is read-only, inspect serve/memory-mcp/src/owlbear_memory_mcp/tools.py::assess_memories. Unlike save_memory, curate_memory, and recall_memory it accepts no agent identity yet mutates assessment metadata and can contest entries. Phrase identity restrictions around creation/curation; tool exposure is a separate boundary.
