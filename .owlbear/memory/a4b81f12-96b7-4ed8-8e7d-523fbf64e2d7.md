In Cockpit Vitest, PDS `PButton` renders a `p-button` host with the native `<button>` inside its open shadow root. Testing Library `getByRole("button", {name})` does not cross that root, so query the host's `shadowRoot` directly. For focus checks, distinguish `document.activeElement` (the host) from `shadowRoot.activeElement` (the inner button).
