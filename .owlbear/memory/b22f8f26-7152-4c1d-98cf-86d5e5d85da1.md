When a Design's Migration says the work builds on an integration-target commit (e.g. macos-managed-browser-authentication requiring dev d4ce5ffa8), check `git merge-base --is-ancestor <commit> HEAD` in the Change worktree before planning. If the branch lacks it, do not plan a Builder merge/cherry-pick: `sync_change_with_target` in serve/delivery/src/owlbear_delivery/application_publication.py is a direct Delivery operation that refuses active claims and converts a pending pause request afterward. Encode a first-task precondition: verify ancestry, else make no commit and pause with an action request for Delivery target sync (conflicts go to the target-conflict workflow).
