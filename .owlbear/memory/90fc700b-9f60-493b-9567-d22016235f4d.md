When reviewing serve/delivery-mcp tool changes, register_target_tools derives each tool's MCP output schema from the handler return annotation. A union annotation such as ModelA | ModelB can silently produce a wrapped/anyOf schema even when the body returns a dict. Prefer a dict-returning adapter with explicit core-model validation and serialization, and verify registered output_schema against an untouched flat tool.
