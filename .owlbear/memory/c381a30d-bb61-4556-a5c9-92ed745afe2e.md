`uv run test serve/<pkg>/tests` (no trailing slash) does not match the `serve/<pkg>/tests/` prefix in `serve/tools/src/owlbear_tools/testing.py::_python_scope`, so it is treated as unknown and falls back to `pytest tests serve` (~5,000 items). For bounded runs pass explicit test files (or a trailing slash); for `--changed`, pass a known `--base` when the worktree has no upstream.
