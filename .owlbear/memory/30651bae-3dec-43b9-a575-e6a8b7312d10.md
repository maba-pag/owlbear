When adding an OwlBear MCP tool and granting it to an agent, check both validation styles. tests/test_agent_ecosystem_validation.py verifies declared non-wildcard grants exist in the live MCP registry, so the tool and grant must land atomically. tests/test_knowledge_ops_contract.py uses a subset comparison and tolerates added grants. tests/test_setup_init_settings.py compares seeded MCP env mappings by exact equality, so new seeded environment keys require explicit test updates.
