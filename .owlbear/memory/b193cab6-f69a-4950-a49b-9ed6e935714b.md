During read-only commit review in this workspace, `git diff`/`git show` output is silently truncated by the terminal git-diff compressor (context lines replaced with `... N unchanged context lines omitted ...`), which can hide diff content that a reviewer must inspect. Read exact committed content with `git cat-file -p <rev>:<path>` (not intercepted), or verify the managed worktree HEAD equals the candidate commit with an empty `git status --porcelain -uall` and then read files directly. Note `git branch` and shell redirection are denied by the read-only terminal guard, so use `git for-each-ref` for branch-ref checks.
