During read-only commit review, `git diff` and `git show` output can be silently truncated by the terminal git-diff compressor, hiding content reviewers must inspect. Read exact committed content with `git cat-file -p <rev>:<path>`, or verify the managed worktree HEAD matches the candidate commit with an empty `git status --porcelain -uall` and then read files directly.
