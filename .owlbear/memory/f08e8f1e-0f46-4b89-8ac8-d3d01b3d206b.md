In task #2006, `serve/kanban/src/owlbear_kanban/invalidation.py` initially treated every affected active-directory job as both a transaction participant and replay member. Terminal cancelled jobs must stay byte-identical, while jobs already superseded by the same receipt must remain in exact replay output. When verifying state-machine replay, derive the mutation set from currently mutable records and the replay set from records owned by that operation identity; test both terminal preservation and exact replay.
