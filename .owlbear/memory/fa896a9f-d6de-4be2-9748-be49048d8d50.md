After `PortfolioApplication` reconciles runtime membership from persisted discovery, hand-assembled Delivery fixtures must write `admission.json` alongside `contract.json` and `frontier.json`; otherwise the Change is observed as an unadmitted Design. Build the fixture through `DeliveryAdmissionReceipt.model_validate` so missing or malformed admission data fails at construction. Check both `serve/cockpit/web/e2e/support/` seeds and manual MCP fixtures, which omit admission independently.
