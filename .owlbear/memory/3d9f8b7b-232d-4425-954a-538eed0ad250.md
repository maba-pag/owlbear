When routing a Delivery consumer through `parse_delivery_frontier()`, check whether it compares original file bytes. `_read_local_snapshot_frontier` must retain caller raw bytes for byte-for-byte drift detection; using the parser's canonical-byte return would make noncanonical local JSON compare equal and weaken reconciliation.
