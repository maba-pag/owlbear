In `serve/cockpit/web/scripts/run-biome-check.mjs`, the wrapper sets Biome's working directory to the repository root (`packageRoot/../../..`). When invoking it from `serve/cockpit/web`, pass paths relative to the repository root, such as `serve/cockpit/web/src/...`; package-relative `src/...` paths resolve incorrectly and Biome reports no files processed.
