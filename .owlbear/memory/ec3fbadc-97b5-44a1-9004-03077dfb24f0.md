`FinalizeDeliveryChange` (serve/delivery/src/owlbear_delivery/runtime_models.py) requires every observation's `task_or_finalization_id` to equal the request `operation_id` and its `exact_commit` to equal `exact_head`; a mismatch returns a generic `ERR_TARGET_PARAM_VALIDATION` with no detail and writes nothing. Decide the user-invoked finalization operation ID before calling `derive_evidence_receipts`, and use that same value as each observation's `task_or_finalization_id`; changing it afterwards changes the observation ID and requires a fresh review.
