In tests/test_package_boundary.py, test_allowlist_covers_current_serve_packages only asserts set equality between discovered serve/*/src/owlbear_* packages and ALLOWED_IMPORTS keys, and test_serve_package_imports_follow_allowlist only flags imports that exist in source. A new shared package can therefore make the suite pass while every consumer entry is still frozenset(). When a task requires admitted consumer directions, read the allowlist values directly in the diff; a passing proof run is not evidence that those edges were admitted.
