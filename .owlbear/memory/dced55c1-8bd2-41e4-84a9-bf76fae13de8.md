In `serve/memory-mcp/src/owlbear_memory_mcp/tools.py`, `list_memories` returns `_metadata_dict` projections without entry content. Acceptance observations that need content must first take the entry ID from `list_memories`, then call `read_memory(entry_id=...)`. `read_memory` allows pending entries and returns content. Content-equality proofs that rely only on `list_memories` are not achievable.
