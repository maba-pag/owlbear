Adding a new spec to serve/cockpit/web/e2e/ does NOT get it executed or typechecked. Both runners use hardcoded default lists: scripts/run-e2e.mjs -> [smoke, pds-runtime-csp]; scripts/run-e2e-compat.mjs -> [smoke, pds-runtime-csp, pds-scheme-dark]. CI (.github/workflows/cockpit-verification.yml) runs `npm run test:e2e:compat` only. playwright.config.ts testDir='e2e' matches the file, but the runner never passes it. tsconfig.e2e.json `include` is also an explicit allowlist (pds-*.spec.ts, smoke.spec.ts, support/*, playwright*.ts), so new specs are unchecked by `npm run typecheck:e2e`. When reviewing or authoring Cockpit E2E work, verify the spec is registered in the runner list and the e2e tsconfig include, otherwise it is dead regression weight.
