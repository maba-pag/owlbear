When reviewing docs that describe which runtime dependencies an assembled test replaces, resolve the test's actual composition-root call rather than its imports: `tests/test_mcp_knowledge_static_refresh.py::_assembled_context` imports the real `HttpxContentFetcher` but wraps it in `httpx.MockTransport` and passes it via `KnowledgeRuntimeFactories.http_response_fetcher_factory`, so a README claiming only the embedding and vector-store factories are replaced overstates production fidelity. Compare the documented substitution set field-by-field with the factory record definition (`serve/knowledge-mcp/src/owlbear_knowledge_mcp/server.py:330-335`).
