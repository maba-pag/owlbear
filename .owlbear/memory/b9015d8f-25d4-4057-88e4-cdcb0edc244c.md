When reviewing a no-false-success claim in `IngestCoordinator.refresh`, do not treat a non-empty `RefreshResult.errors` tuple as proof: partial refreshes legitimately carry errors while marking the source refreshed. Assert the state mutation: total processing failure must leave `sources.update_source` uncalled and `sources_refreshed == 0`; partial success and zero-document no-error no-op should call update and report `sources_refreshed == 1`.
