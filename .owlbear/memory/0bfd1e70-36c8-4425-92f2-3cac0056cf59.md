`parse_delivery_frontier()` in `serve/delivery/src/owlbear_delivery/runtime_support.py` delegates to `parse_stored_delivery_frontier()`, which raises a bare `TypeError` when decoded JSON is not an object and a bare `ValueError` for an unsupported `schema_version`, before Pydantic validation. A consumer catching only `ValueError` or `ValidationError` can leak the non-object case; inspect the parser's exception types when migrating callers.
