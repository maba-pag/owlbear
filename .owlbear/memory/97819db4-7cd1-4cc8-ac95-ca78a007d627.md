In Cockpit (Porsche Design System React 4.x), host attributes such as `aria-describedby` on `PButton` are not forwarded to the native button inside its shadow root, so screen readers miss them, while jsdom `toHaveAccessibleDescription` still passes on the host. Use the PDS `aria` prop instead, e.g. `aria={{ "aria-description": TEXT }}`; its ButtonAriaAttribute allowlist includes it and the renderer spreads it onto the native button. In vitest, assert the element's `.aria` property, not the host attribute.
