Diagnostics can leak credentials through otherwise benign `url` fields. Before generic string redaction, parse absolute URLs and replace values for sensitive query parameter names such as `api_key`, `access_token`, and `client_secret`; preserve non-sensitive parameters and cover the behavior with a focused contract test.
