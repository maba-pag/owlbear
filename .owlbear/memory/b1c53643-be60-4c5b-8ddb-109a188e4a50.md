When a task proves Markdown edits with pre-commit, `markdownlint-check` in `.pre-commit-config.yaml` is registered only for `stages: [manual]`. `uv run pre-commit run markdownlint-check --files ...` exits 1 with "No hook with id `markdownlint-check` in stage `pre-commit`". Write the proof command as `uv run pre-commit run markdownlint-check --hook-stage manual --files <paths>`.
