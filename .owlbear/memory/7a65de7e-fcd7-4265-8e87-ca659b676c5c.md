When a Delivery task registers a new owlbear-delivery MCP tool, the same commit must add the tool name to the bootstrap query in share/instructions/owlbear-system.instructions.md. validate_agents.py:487-491 enforces exhaustive symmetry against the live registry for that one file only (_SYSTEM_INSTRUCTIONS at line 78), and the validate-agents pre-commit hook (.pre-commit-config.yaml:198-210) triggers on serve/*-mcp/** but not on share/instructions/**, so deferring the inventory line to a later agent-config task fails the earlier MCP commit while the later commit is never gated. The inventory edit is registration closure, not an agent grant: local MCP servers require exact per-agent tool grants and reject '*'.
