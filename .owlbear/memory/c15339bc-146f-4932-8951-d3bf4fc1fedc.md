When reviewing OwlBear Delivery read projections, check which retained-worktree source a change uses: ChangeWorkspaceManager.list_retained (serve/delivery/src/owlbear_delivery/change_workspace.py:2010-2017) drops any Change holding a cleanup receipt with no Git registration or directory, while inspect_retained (same file, :2029-2039) synthesizes a RetainedChangeWorktree unconditionally. Swapping list_retained for inspect_retained in publication detail resurrects worktree_cleanup/worktree_recovery for already-cleaned worktrees and surfaces an eligible recovery action that change_workspace.py:1517-1518 fail-closes with 'Change worktree has already been cleaned up'.
