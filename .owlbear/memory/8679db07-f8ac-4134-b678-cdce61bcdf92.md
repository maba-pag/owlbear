When reviewing an MCP tool surface, verify policy enforcement per operation rather than assuming server-level coverage. In `serve/browser-mcp/src/owlbear_browser_mcp/server.py`, `acquire` and `navigate` run destination checks, while `click`, `type_input`, and `select` can trigger navigation on the shared page without the same guard. Put policy at the navigation boundary or prove each mutator cannot cross it.
