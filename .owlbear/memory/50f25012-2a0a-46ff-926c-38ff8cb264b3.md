In `serve/tools/src/owlbear_tools/testing.py`, `_python_scope` returns the literal path for a `.py` file whose name starts with `test_` after package-prefix routing. Thus `uv run test tests/test_x.py` or an unrouted package test such as `serve/web-content/tests/test_web_content.py` remains a bounded exact-file proof; whole-workspace fallback applies only to unmatched non-test changed paths.
