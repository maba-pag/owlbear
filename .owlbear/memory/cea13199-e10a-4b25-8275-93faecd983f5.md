On macOS managed Edge, closing the last visible window can leave Playwright's persistent BrowserContext open without emitting `close`; `context.pages` becomes empty. `PlaywrightLauncher.is_running` should require a nonempty page list as well as a live context. Keep it running when another page remains; test both cases because a close-event-only fake misses the operator window-close path. See `serve/browser/src/owlbear_browser/playwright_launcher.py` and its launcher/lifecycle tests.
