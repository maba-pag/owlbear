In `.github/workflows/sync-to-main.yml`, serve scope names from `.github/sync-manifest.json` are mapped to `SYNC_*`/`*_PATHS` env vars. Bash `${scope^^}` silently yields an invalid identifier for hyphenated scopes (e.g. `web-content` -> `WEB-CONTENT`), so every site must use `scope_suffix=$(printf '%s' "$serve_scope" | tr '[:lower:]-' '[:upper:]_')` — there are five such sites (lines ~133, 202, 245, 323, 432), and missing one leaves a silently unsynced scope. Also note consumer projection drops package tests via the generic `find serve -mindepth 2 -maxdepth 2 -type d -name tests` prune step, not via `consumer_excluded_paths`, so new packages need no manifest exclusion entry.
