In `yaml target-contract` blocks, `serve/delivery/src/owlbear_delivery/target_contract.py` parses YAML with ruamel. In an unquoted scalar such as a decision or commitment `statement`, ` #` starts a comment, so issue references like `... #234 owns cleanup` are silently truncated. `derive_delivery_contract` still succeeds with no diagnostic. Quote every statement, basis, or promise that contains ` #NNN` before deriving. Then confirm the derived contract text matches the authored text, so designer-challenger does not report an error round for the lost text.
