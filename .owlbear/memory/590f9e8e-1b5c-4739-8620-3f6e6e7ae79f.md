When forwarding a worker result through `transition_delivery`, wrap the call as `request: {change_id: <launch change>, request: <unchanged DeliveryTransition>}`. Passing the transition fields directly to the tool argument produces validation errors before Delivery can process the claim and requires exact claim recovery.
