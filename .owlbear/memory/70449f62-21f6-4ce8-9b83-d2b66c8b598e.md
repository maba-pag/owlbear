`serve/web-content/src/owlbear_web_content/__init__.py` exports extraction and cleaning callables, but non-HTML normalization remains private as `cleaner._normalize_content`; `clean()` parses HTML first and `extract()` does not normalize afterward. Plans requiring plain text or Markdown normalization without HTML extraction must include a public shared normalizer and the `serve/web-content` test boundary.
