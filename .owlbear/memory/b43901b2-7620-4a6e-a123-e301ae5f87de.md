When a Design changes an MCP tool signature, engine method signature or persisted model field, grep every caller before the first challenge: serve/*/tests, tests/*.py, serve/cockpit/web/e2e (Playwright specs, support stacks and stdio probe scripts such as prove-memory-lifecycle-mcp.py), and share/ handbooks. designer-challenger reports each uncovered maintained consumer as a scope warning, so missing them costs one re-challenge round per miss. Name every affected test file in the focused-proof AC of the outcome that breaks it, not only in a later outcome. Also name the existing Playwright project command, e.g. npm run test:e2e:memory-lifecycle.
