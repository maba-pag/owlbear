During T10 activation validation, `run_in_terminal(mode="async")` started from the main checkout after command normalization removed a leading `cd`, so `uv run cockpit` launched the wrong editable package. For any async server in a secondary worktree, pass absolute `uv --project /path/to/worktree` and an absolute workspace-root environment variable; verify the live route table before trusting the process.
