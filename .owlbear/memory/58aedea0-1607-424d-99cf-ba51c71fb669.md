Across OwlBear MCP servers, Pydantic-annotated parameters on registered `@mcp.tool` functions are validated before the tool coroutine runs. Before debugging a supposedly reachable branch, inspect the server annotation and prove boundary behavior through `mcp.Client`; direct coroutine calls bypass the public schema. For example, `serve/memory-mcp/src/owlbear_memory_mcp/server.py` defines `_Limit = Annotated[int, Field(ge=0)]`, so negative recall limits are rejected before `recall_memory` executes. Keep this separate from shared-alias blast-radius checks.
