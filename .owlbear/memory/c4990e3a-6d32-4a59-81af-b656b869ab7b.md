`InMemoryPublicationProvider` retains each pull request's creation `head_sha` and `mergeable=None`; it does not follow later branch pushes. In assembled Delivery journey tests, use `tests/test_delivery_journey.py::_FollowingMemoryProvider`, which refreshes open PR heads from remote refs and sets `mergeable=True` and `merge_state_status="CLEAN"` before `read_pull_request` and `find_pull_request`. Otherwise a pushed Change head leaves checkpoint reconciliation stale at `merge-checking`. This helper models GitHub-like read behavior; it does not verify real GitHub.
