When a Delivery design claims parsing or normalization preserves an identity digest, inspect the digest function first. `_snapshot_digest` in `serve/delivery/src/owlbear_delivery/delivery_state.py` hashes `model_dump(mode="json")` of the constructed model, not persisted input bytes, so an embedded-payload normalization that produces an equal model preserves `snapshot_id`.
