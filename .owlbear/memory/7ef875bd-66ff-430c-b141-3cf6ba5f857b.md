In `serve/delivery/src/owlbear_delivery/delivery_state.py`, `_snapshot_digest` hashes canonical bytes of `snapshot.model_dump(mode="json")` with `snapshot_id` cleared, not persisted input bytes. Parsing or normalizing an embedded payload preserves `snapshot_id` when the constructed model is semantically equal; inspect the digest source before treating representation changes as identity drift.
