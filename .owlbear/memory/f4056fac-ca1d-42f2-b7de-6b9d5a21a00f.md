When validating a task's `uv run test <path>` proof boundary, read `_PYTHON_ROUTES` in serve/tools/src/owlbear_tools/testing.py rather than the test-domain table in .github/copilot-instructions.md. The runner registers routes the instructions table omits (for example `serve/delivery-github/` to `serve/delivery-github/tests`, listed before `serve/delivery/` so the more specific prefix wins). Judging routing from the instructions table alone can falsely classify a domain proof as a whole-workspace fallback.
