In task #1976, `serve/cockpit/web/src/components/TaskFieldsEditor.tsx` hid a complete PDS edit form while display mode was active. PDS 4.5 still queued `SelectOption.onSlotChange` teardown work for those hidden selects, and a large Vitest file stalled after assertions. When a real-PDS jsdom suite hangs at teardown, first check whether inactive UI remains mounted; conditionally mount the custom-element subtree through its public user transition, then prove both the focused prefix and unsharded command terminate.
