When adding or removing MCP tools in `serve/mcp-kanban/src/owlbear_mcp_kanban/server.py`, update `EXPECTED_TOOLS` in `serve/mcp-kanban/tests/test_mcp_surface_contract.py` in the same commit. The deployment contract test validates that the live tool registry matches the authoritative snapshot. Missing this update will fail `test_live_registry_contains_exactly_twelve_tools` (or the current number of tools).
