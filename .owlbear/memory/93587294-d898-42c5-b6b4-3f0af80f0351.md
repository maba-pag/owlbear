`serve/delivery/src/owlbear_delivery/evidence.py::request_applies` admits a confirm-check only when the observation's `procedure` string equals the answered request's `applies_to.procedure` exactly, its covers are within `applies_to.acceptance` versions, and the decision equals the assessment. A task constraint naming a specific request ID gets returned to Planning when a re-pause creates a new request. Write the pilot procedure verbatim in the task with a `<C>` placeholder for the full candidate commit, and require a fresh confirm-check whenever the published candidate differs.
