To run fixed Delivery code against a copy of a consumer project's partial state: copy the project, mount the copy in an ubuntu:24.04 container at the project's ORIGINAL absolute path (coordination records and worktree .git files hold absolute paths; a host-side copy would make the app write into the original). Do not `git remote set-url origin <bare>`: the default loader refuses a remote URL that is not github.com form matching `github_repository`. Instead set `url.<local-bare-mirror>.insteadOf <github url>` in the copy's .git/config and mount the mirror; load with `load_configured_delivery_application(root, load_delivery_config, publication_provider=None)` so no GitHub provider call happens. Hash runtime records and refs of the original before/after.
