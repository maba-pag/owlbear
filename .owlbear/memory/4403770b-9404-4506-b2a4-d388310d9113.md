`serve/cockpit/web/e2e/support/seed-work-portfolio-delivery.py` instantiates production Delivery models directly (`DeliveryHostConfig`, `PortfolioCoordinator`, `ChangeWorkspaceManager`), and no Python unit suite imports it, so signature or Pydantic-schema changes in `serve/delivery/src/owlbear_delivery/{delivery_application_loader,change_workspace}.py` break it silently until `npm run test:e2e:work` runs. When changing those constructors, grep `serve/cockpit/web/e2e/support/` for the symbol and treat the E2E gate as the covering proof.
