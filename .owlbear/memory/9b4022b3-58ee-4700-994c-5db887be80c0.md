In this repo, `serve/*` packages are editable workspace members, so `uv run pytest` resolves cross-package imports (e.g. `owlbear_delivery_github` from `serve/delivery/tests/`) without any `PYTHONPATH=...` prefix, even though `[tool.pytest.ini_options] pythonpath` lists only `serve/delivery/src` and `serve/tools/src`. Verify with `uv run --locked python -c "import <pkg>"` before accepting a PYTHONPATH-prefixed proof command; a prefixed command can mask a test that would not resolve under the standard runner.
