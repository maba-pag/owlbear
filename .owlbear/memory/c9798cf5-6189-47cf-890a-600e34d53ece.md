When reviewing a Cockpit frontend task chain, check the render condition of every UI control an acceptance observation activates, not just its existence. In `serve/cockpit/web/src/pages/MemoryTab.tsx`, `clear-filters` renders only inside `hasEntries && !hasVisibleEntries`, so an observation activating it after a filter that still yields matches is unexecutable. Read the control's enclosing JSX conditional before passing observations phrased as “activate X after Y.”
