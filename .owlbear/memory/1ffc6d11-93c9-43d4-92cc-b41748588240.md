Adding even an optional, exclude-when-None field to a Delivery model that is embedded in persisted records (e.g. RetryDelivery inside the frontier, settlement receipts and snapshot) changes their owner-schema fingerprints. serve/delivery/tests/test_state_formats.py then demands schema_version bumps plus read-upcasts for every affected record kind. Prefer a new versioned sidecar record kind written in the same RuntimeTransaction: register it in state_formats.py, tests/fixtures/state_formats.json, a golden record, the _WRITER_FORMATS table, and owlbear_tools.delivery_diagnostics (tree, version table, path, plus its test fixtures). Focused suites miss these guards. Before pushing, run `uv run test --changed --py --base origin/dev`, which includes the invariant tests (state formats, fetch-vector allowlist, workspace-manager Pause classes, diagnostics coverage).
