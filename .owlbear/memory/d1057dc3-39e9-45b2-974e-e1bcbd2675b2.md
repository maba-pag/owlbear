New serve packages must be admitted in the package-boundary allowlist. tests/test_package_boundary.py auto-discovers every serve/*/src/owlbear_* directory but compares it with hard-coded ALLOWED_IMPORTS; adding a package therefore requires a matching allowlist entry, and a new-package task plan should include that root test surface. The root pyproject.toml already globs serve/*, so inspect the boundary allowlist first.
