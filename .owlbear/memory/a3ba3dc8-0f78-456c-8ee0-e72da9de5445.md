When a change touches an MCP composition root or shared persistence wiring, do not rely only on package-routed tests: cross-cutting lifespan or wiring tests may live outside the matching domain route. Inspect `serve/tools/src/owlbear_tools/testing.py` for the actual route and run the directly relevant wiring test explicitly, such as `tests/test_persistence_source_wiring.py`, so constructor and lifespan regressions cannot hide behind a green domain run.
