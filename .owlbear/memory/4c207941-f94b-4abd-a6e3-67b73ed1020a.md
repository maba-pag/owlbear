In `serve/delivery/src/owlbear_delivery/storage_io.py`, `locked_roots` creates the lock directory and `.storage.lock`; wrapping provider I/O with it makes an MCP read operation mutate local lock state and hold an exclusive lock across network latency. For Delivery read paths, use the shared state lock only for the bounded local read, then rely on explicit provider pre/post identity fences.
