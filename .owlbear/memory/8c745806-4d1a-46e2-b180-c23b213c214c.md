In task #1991, `serve/kanban/src/owlbear_kanban/change.py` deep-froze nested JSON with `MappingProxyType` and tuples so a frozen `ChangeRevision` was truly immutable. Pydantic then raised `PydanticSerializationError` from `model_dump(mode="json")`. For public frozen models that also feed APIs, add a field serializer that thaws mapping proxies and tuples to JSON dicts/lists, and prove both nested mutation rejection and JSON projection.
