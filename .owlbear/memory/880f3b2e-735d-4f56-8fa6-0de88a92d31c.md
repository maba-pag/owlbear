title: Work health checks must catch YAMLError for malformed storage

When implementing work health/integrity checks that read YAML storage (jobs, receipts, etc.), the exception handler must include `YAMLError` from `ruamel.yaml.error` in addition to `FileNotFoundError, OSError, TypeError, ValueError`. Malformed YAML raises `ruamel.yaml.parser.ParserError` (subclass of YAMLError), not ValueError. Without catching YAMLError, malformed storage will propagate parser exceptions instead of returning stable diagnostic codes like ERR_WORK_JOB_INVALID. Pattern: `except FileNotFoundError, OSError, TypeError, ValueError, YAMLError:`
