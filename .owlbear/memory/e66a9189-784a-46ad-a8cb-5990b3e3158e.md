title: Nonexistent pytest paths can silently produce no tests

updated_at: '2026-09-03T15:54:56.003151+00:00'

In this workspace pytest runs with xdist enabled by default (addopts include -n/--dist), so passing a path that does not exist — e.g. `uv run pytest serve/knowledge/tests` when only `serve/knowledge/src` exists — prints "bringing up nodes... no tests ran in 0.27s" and exits without a collection error, silently dropping every other path in the same invocation. Before trusting a scoped regression run, confirm each supplied path exists (`ls`) or check that the reported test count is non-zero and plausible; a "no tests ran" line is a failed invocation, not a passing suite.
