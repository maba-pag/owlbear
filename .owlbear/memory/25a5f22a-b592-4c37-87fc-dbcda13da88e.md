When reviewing HTML-to-Markdown extraction with trafilatura, do not treat a non-empty trafilatura.extract(..., output_format="markdown", include_links=True) result as structurally complete: it can return prose that lost link destinations present in the source. In serve/web-content/src/owlbear_web_content/extractor.py, compare link targets from the structural lxml fallback with the library result and fall back when any target is missing. Fixture assertions should name an exact href such as https://example.com/target, not merely assert non-empty output.
