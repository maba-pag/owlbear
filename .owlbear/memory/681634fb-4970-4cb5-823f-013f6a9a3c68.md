When a design launches an application-owned persistent browser profile and promises visible authentication, explicitly identify how the operator reaches and interacts with that owned window. Exclusive user-data-directory locking prevents out-of-band use while the server runs. Keep browser/profile readiness separate from target acquisition classification, and do not defer every page-retention mechanism while still promising first-use authentication.
