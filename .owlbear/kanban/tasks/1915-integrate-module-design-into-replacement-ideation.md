## Deferred Context
The current ideation flow and spec-kit are being replaced. Do not modify or preserve those retiring artifacts for this work. Apply this task only after the replacement ideation architecture and artifact contract are concrete.

## Required Integration
- Load `h-project-orientation` for existing-system landscape work; generated indexes and Semble locate candidates, while source remains authoritative.
- During architecture approach comparison, apply `r-architecture-standards` depth, locality, leverage, and Deletion Test diagnostics. Prefer cohesive modules with small interfaces; reject shallow forwarding boundaries and speculative adapters.
- The approved Brief carries an approach-level module map: module/package responsibility, intended change, interface impact, and unresolved ownership questions. It must not invent exact source paths or symbols before codebase verification.
- Shaping remains responsible for verifying source and converting the approach-level map into the concrete Change Module Map in Shape Notes.

## Scope Boundary
This task does not redesign ideation itself. It wires these requirements into the replacement flow once that flow exists.

Proof guidance: inspect the replacement ideation artifact contract and run agent ecosystem reference checks.
