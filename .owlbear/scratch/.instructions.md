# Scratch File Placement Rules

Use this folder for temporary agent artifacts only.

## Placement

- Store all agent temp/debug output under .owlbear/scratch/{task-id}-{desc}.{ext}.
- Do not write temporary output files to the repository root or tracked product directories.

## Cleanup

- Before marking a task done, delete any .owlbear/scratch/{task-id}-\* files created for that task. Keep this file and .gitkeep.

## Naming examples

- .owlbear/scratch/88-pytest-output.txt
- .owlbear/scratch/142-kanban-show.json
