# Scratch File Placement Rules

Use this folder for temporary agent artifacts only.

## Placement

- Store all agent temp/debug output under docs/scratch/{task-id}-{desc}.{ext}.
- Do not write temporary output files to the repository root.

## Cleanup

- Before marking a task done, delete any docs/scratch/{task-id}-\* files created for that task.

## Naming examples

- docs/scratch/88-pytest-output.txt
- docs/scratch/142-kanban-show.json
